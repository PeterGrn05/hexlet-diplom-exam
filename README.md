### Цели дипломного проекта

В этой дипломной работе я создал собсвтенный сайт для бронирования билетов в кинотеатр и разработал информационную систему для администрирования залов, сеансов и предварительного бронирования билетов через React и Django.

### Описание проекта

#### 1. Сущности

- **Кинозал** – помещение, в котором демонстрируются фильмы. Режим работы определяется расписанием на день. Зал — прямоугольный, состоит из `N*M` различных зрительских мест.

- **Зрительское место** – место в кинозале: стандартное или VIP-место.

- **Фильм** – информация о фильме заполняется администратором. Фильм связан с сеансом в кинозале.

- **Сеанс** – это временной промежуток, в котором в кинозале будет показываться фильм. На сеанс могут быть забронированы билеты.

- **Билет**  – QR-код c кодом бронирования, в котором обязательно указаны: Дата, Время, Название фильма, Зал, Ряд, Место, Стоимость, 

#### 2. Роли пользователей системы

-   Гость — неавторизованный посетитель сайта.
-   Администратор — авторизованный пользователь.

#### 3. Возможности гостя
-   Просмотр расписания
-   Просмотр информации о фильмах
-   Выбор места в кинозале
-   Бронирование билета

#### 4. Возможности администратора
-   Создание или редактирование залов.
-   Создание или редактирование списка фильмов.
-   Настройка цен.
-   Создание или редактирование расписания сеансов фильмов.
-   Открытие или закрытие продаж залов, с которым связанны сеансы

## Как правильно запустить проект локально:

Открываем два терминала в Visual Studio Code (т.е. делаем комбинацию CTRL + Shift + ` )

### Первый Терминал - cd backend

Для начала активируем venv. Вводим python3 -m venv venv

Затем активируем через source venv/bin/activate

(Если у вас по-другому установлен python или другой WSL, попробуйте другие методы активации.)

После активации venv, устанавливаем requirements через pip install -r requirements.txt

Ну и наконец, включаем сервер через python3 manage.py runserver

### Второй Терминал - cd frontend

Там уже сразу же пишем npm install

После этого пишем npm start.
